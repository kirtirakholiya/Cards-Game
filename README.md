Cards Game API – PHP Backend

This project is a simple PHP API built to handle the core logic and data flow for a cards game. It manages game sessions, card distribution, player actions and result handling through structured and easy-to-extend endpoints. The codebase is organized for readability and follows clean practices so new features can be added without complexity.

Key features

Card deck generation and shuffling
Player turn handling
Game state management
Score calculation and result output
JSON based responses
Clear routing and separation of logic

Tech stack

PHP
REST style API structure
JSON data exchange

This project is a base that can be expanded for multiplayer mode, UI integration or more advanced game rules.
